## เครื่องมือในชุดนี้

### `quotation.html` — ใบเสนอราคา / ใบแจ้งหนี้ / ใบวางบิล / ใบเสร็จรับเงิน / ใบกำกับภาษี

- กรอกข้อมูลลงบนกระดาษได้ตรง ๆ แล้วสั่งพิมพ์เป็น PDF (A4)
- คำนวณ VAT 7% และส่วนลดให้อัตโนมัติ
- **แปลงยอดเงินเป็นตัวอักษรไทยให้อัตโนมัติ** เช่น `53,821.00` → `ห้าหมื่นสามพันแปดร้อยยี่สิบเอ็ดบาทถ้วน`
- ใส่โลโก้ร้านได้
- จำข้อมูลร้านและเอกสารล่าสุดไว้ในเครื่อง (localStorage) ครั้งต่อไปกรอกแค่รายการสินค้า

### `promptpay.html` — สร้าง QR พร้อมเพย์

- ใส่เบอร์โทรหรือเลขบัตรประชาชนที่ผูกพร้อมเพย์ กำหนดยอดเงินได้ (หรือเว้นว่างให้คนจ่ายกรอกเอง)
- สร้าง payload ตามมาตรฐาน EMVCo (CRC16-CCITT) แบบเดียวกับที่แอปธนาคารไทยใช้
- ดาวน์โหลดรูป QR ไปติดหน้าร้านหรือส่งให้ลูกค้าได้ทันที
- หมายเหตุ: ไฟล์นี้โหลดไลบรารีวาด QR จาก CDN จึงต้องต่ออินเทอร์เน็ตครั้งแรกที่เปิด

### `bank-qr.html` — สร้าง QR โอนเข้าบัญชีธนาคาร

- สร้าง QR ที่บรรจุ **รหัสธนาคาร 3 หลัก + เลขที่บัญชี** ไว้ในช่อง Tag 29 sub-tag `04` ของมาตรฐาน Thai QR Payment
  ลูกค้าสแกนแล้วแอปธนาคารเติมธนาคารปลายทางและเลขบัญชีให้เอง ไม่ต้องพิมพ์ตามป้าย
- รองรับพร้อมเพย์แบบเบอร์โทร (`01`), เลขบัตรประชาชน / เลขผู้เสียภาษี (`02`) และ e-Wallet ID (`03`) ในหน้าเดียวกัน
- payload ทุกแบบถูกตรวจสอบว่าตรงกับไลบรารีอ้างอิง `promptparse` และ `thai-qr-payment` แบบตัวต่อตัว
- ⚠️ **ข้อจำกัดที่ต้องรู้:** sub-tag `04` มีอยู่ในสเปคจริง แต่แอปธนาคารแต่ละแห่งรองรับไม่เท่ากัน
  บางแอปสแกนได้ บางแอปฟ้องว่า QR ไม่ถูกต้อง ต้องทดสอบกับแอปที่ลูกค้าใช้จริงก่อนพิมพ์ป้าย
  ถ้าไม่รองรับให้สลับไปใช้แบบพร้อมเพย์ในหน้าเดียวกันได้ทันที
- หมายเหตุ: ไฟล์นี้โหลดไลบรารีวาด QR จาก CDN จึงต้องต่ออินเทอร์เน็ตครั้งแรกที่เปิด

### `withholding-tax.html` — คำนวณภาษีหัก ณ ที่จ่าย

- รองรับอัตรา 1% (ขนส่ง), 2% (โฆษณา), 3% (บริการ/จ้างทำของ/วิชาชีพอิสระ), 5% (ค่าเช่า), 10% (ปันผล)
- กรอกยอดแบบก่อน VAT / รวม VAT / ไม่มี VAT ได้ — ระบบถอดฐานให้เองและหักจากฐานก่อน VAT เสมอ
- บอกครบ: ฐาน, VAT, ยอดหัก, ยอดโอนจ่ายจริง

### `vat.html` — คำนวณ VAT 7%

- บวก VAT จากราคาก่อนภาษี หรือถอด VAT จากราคารวม (×100÷107)

### `cost-per-unit.html` — คำนวณต้นทุนต่อแก้ว / ต่อจาน

- ใส่วัตถุดิบได้หลายรายการ แต่ละรายการกรอก ราคาที่ซื้อ / ปริมาณที่ซื้อ / ปริมาณที่ใช้ต่อเมนู
- บอกต้นทุนของวัตถุดิบแต่ละตัว ต้นทุนรวมต่อเมนู กำไรต่อเมนู และเปอร์เซ็นต์กำไร
- หน่วยเป็นหน้าที่ผู้ใช้กำหนดเอง ขอแค่ "ปริมาณที่ซื้อ" กับ "ใช้ต่อเมนู" เป็นหน่วยเดียวกัน
- คิดเฉพาะต้นทุนต่อเมนู ไม่รวมค่าเช่า ค่าน้ำค่าไฟ เงินเดือน และของเสีย เว้นแต่ผู้ใช้เฉลี่ยใส่ช่อง "ต้นทุนอื่น" เอง

## วิธีใช้ (สำหรับเจ้าของธุรกิจ)

1. กดปุ่ม **Code → Download ZIP** ด้านบนของหน้านี้ (หรือดาวน์โหลดเฉพาะไฟล์ `quotation.html`)
2. ดับเบิลคลิกไฟล์ `quotation.html` — เปิดในเบราว์เซอร์ได้ทันที **ไม่ต้องต่ออินเทอร์เน็ต**
3. กรอกข้อมูล แล้วกด **พิมพ์ / บันทึก PDF** → เลือกปลายทางเป็น "Save as PDF"

## ความเป็นส่วนตัว

ทุกอย่างทำงานในเบราว์เซอร์ของคุณเท่านั้น ข้อมูลลูกค้าและยอดเงิน **ไม่ถูกส่งออกไปที่ไหนทั้งสิ้น**
ข้อมูลที่จำไว้ถูกเก็บใน `localStorage` ของเบราว์เซอร์เครื่องนั้น ล้างได้ด้วยปุ่ม "ล้างข้อมูล"

## สำหรับนักพัฒนา

ไม่มี build step ไม่มี dependency — HTML + CSS + JavaScript ล้วนในไฟล์เดียว
แก้ไฟล์แล้วรีเฟรชเบราว์เซอร์ได้เลย (ยกเว้น `promptpay.html` และ `bank-qr.html` ที่โหลดไลบรารีวาด QR จาก CDN)

รันชุดตรวจสอบในตัว (ตัวเลขเป็นตัวอักษรไทย + การคำนวณยอด) ด้วยการเปิด:

```
quotation.html?selftest=1
```

ผลลัพธ์จะขึ้นเป็นกล่องดำมุมขวาล่าง ถ้าแก้โค้ดส่วนคำนวณ กรุณารันอันนี้ก่อนส่ง PR
