# เครื่องมือฟรีสำหรับธุรกิจไทย — โดย ลำพูน AI Tech

เครื่องมือเล็ก ๆ ที่ทำงานได้จริง **ไฟล์เดียว เปิดด้วยเบราว์เซอร์ ไม่ต้องติดตั้งอะไรเลย**
ไม่มีเซิร์ฟเวอร์ ไม่มีการสมัครสมาชิก ไม่เก็บข้อมูลผู้ใช้

👉 ใช้งานออนไลน์: <https://lamphunaitech.aecaichang.com/tools/quotation>

---

## เครื่องมือในชุดนี้

### `quotation.html` — ใบเสนอราคา / ใบแจ้งหนี้ / ใบวางบิล / ใบเสร็จรับเงิน / ใบกำกับภาษี

- กรอกข้อมูลลงบนกระดาษได้ตรง ๆ แล้วสั่งพิมพ์เป็น PDF (A4)
- คำนวณ VAT 7% และส่วนลดให้อัตโนมัติ
- **แปลงยอดเงินเป็นตัวอักษรไทยให้อัตโนมัติ** เช่น `53,821.00` → `ห้าหมื่นสามพันแปดร้อยยี่สิบเอ็ดบาทถ้วน`
- ใส่โลโก้ร้านได้
- จำข้อมูลร้านและเอกสารล่าสุดไว้ในเครื่อง (localStorage) ครั้งต่อไปกรอกแค่รายการสินค้า

## วิธีใช้ (สำหรับเจ้าของธุรกิจ)

1. กดปุ่ม **Code → Download ZIP** ด้านบนของหน้านี้ (หรือดาวน์โหลดเฉพาะไฟล์ `quotation.html`)
2. ดับเบิลคลิกไฟล์ `quotation.html` — เปิดในเบราว์เซอร์ได้ทันที **ไม่ต้องต่ออินเทอร์เน็ต**
3. กรอกข้อมูล แล้วกด **พิมพ์ / บันทึก PDF** → เลือกปลายทางเป็น "Save as PDF"

## ความเป็นส่วนตัว

ทุกอย่างทำงานในเบราว์เซอร์ของคุณเท่านั้น ข้อมูลลูกค้าและยอดเงิน **ไม่ถูกส่งออกไปที่ไหนทั้งสิ้น**
ข้อมูลที่จำไว้ถูกเก็บใน `localStorage` ของเบราว์เซอร์เครื่องนั้น ล้างได้ด้วยปุ่ม "ล้างข้อมูล"

## สำหรับนักพัฒนา

ไม่มี build step ไม่มี dependency ไม่มี CDN — HTML + CSS + JavaScript ล้วนในไฟล์เดียว
แก้ไฟล์แล้วรีเฟรชเบราว์เซอร์ได้เลย

รันชุดตรวจสอบในตัว (ตัวเลขเป็นตัวอักษรไทย + การคำนวณยอด) ด้วยการเปิด:

```
quotation.html?selftest=1
```

ผลลัพธ์จะขึ้นเป็นกล่องดำมุมขวาล่าง ถ้าแก้โค้ดส่วนคำนวณ กรุณารันอันนี้ก่อนส่ง PR
